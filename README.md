# Betonolom UA

Простий сайт для демонтажних робіт із формою заявки та Telegram-ботом.

## Запуск

1. Встановіть залежності:
   ```bash
   npm install
   ```
2. Скопіюйте `.env.example` у `.env` та вкажіть токен бота:
   ```bash
   copy .env.example .env
   ```
3. Запустіть застосунок:
   ```bash
   npm start
   ```

## Як працює

- Сайт доступний на `http://localhost:3000`
- Форма заявки надсилає дані на сервер
- Сервер пересилає заявку в Telegram першому авторизованому користувачеві
- Бот приймає команду `/start` і зберігає першого користувача як єдиного отримувача заявок

## Налаштування

- `TELEGRAM_BOT_TOKEN` — токен від BotFather
- `PORT` — порт сервера
